### 1. **Estructura de Archivos**
Primero, crea una estructura de directorios que te permita organizar tus archivos de manera eficiente. Aquí hay
una propuesta de estructura:

```
/your-project-name
  ├── index.html          # Página Home
  ├── catalogo.html       # Página Catalogo
  ├── item-details.html   # Página de detalles del item
  ├── assets
  │   ├── images         # Imágenes de los items
  │   ├── styles.css      # Archivo de estilo CSS
  │   ├── script.js      # Archivo de script JavaScript
  ├── order.html          # Página de confirmación de orden
  ├── order.js            # Script para manejar la orden de compra
  └── README.md           # Documentación del proyecto
```

#### 2.7. `order.js`
```javascript
document.addEventListener('DOMContentLoaded', function() {
    const orderItems = document.getElementById('orderItems');
    const totalPrice = document.getElementById('totalPrice');
    const items = JSON.parse(localStorage.getItem('cart')) || [];

    items.forEach(item => {
        const itemElement = document.createElement('li');
        itemElement.textContent = `Item ${item} - $100.00 ARS`; // Ajusta el precio según sea necesario
        orderItems.appendChild(itemElement);
    });

    totalPrice.textContent = `$${items.length * 100.00} ARS`; // Ajusta el precio según sea necesario
});
```

### 3. **Pasos Adicionales**
1. **Imágenes**: Coloca las imágenes de los items en la carpeta `assets/images/`.
2. **Página de Detalles de Item**: Modifica `item-details.html` para que tome el `id` del item de la URL y
muestre la información correspondiente.
3. **Funcionalidad de Carrito**: Implementa la lógica para agregar items al carrito y mostrar el carrito en
`order.html`.
4. **Envío de Orden**: Implementa la lógica para enviar el carrito al email utilizando un servidor back-end.

### 4. **Publicación en GitHub Pages**
1. Inicializa tu repositorio en GitHub.
2. Sube todos los archivos a tu repositorio.
3. Ve a la configuración de tu repositorio en GitHub y habilita GitHub Pages.
4. Selecciona la rama `main` (o `master` si es tu caso) y el directorio raíz.
5. Haz clic en `Save`.
